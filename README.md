# Wildlife-Vehicle Collision Data Story & Visual Analysis 🚗🦌

An exploratory data analysis (EDA) and data storytelling project focused on analyzing wildlife-vehicle collision patterns to identify environmental and public safety insights.

---

##  Project Overview & Requirements

This project fulfills the requirements for a comprehensive Python-based data story:
- **Topic:** Public Transport, Traffic, and Climate/Environment
- **Tools:** Python (Pandas, NumPy, Matplotlib, Seaborn)
- **Output:** Exploratory Python Notebook, Visualizations, and Video Presentation/Documentary

---

##  Key Insights & Findings

1. **Biodiversity Impact:** Identification of animal classes and top species most impacted by vehicular collisions.
2. **Seasonal Peaks:** Monthly incident spikes correlated with seasonal migrations and weather patterns.
3. **High-Risk Time Windows:** Hourly incident distributions highlighting peak danger hours for drivers and wildlife (e.g., dusk to dawn).

---

##  Data Pipeline & Methodology

- **Dataset Selection:** Sourced from reliable wildlife management / traffic collision records.
- **Data Cleaning:** Column normalization (handling standard & `MultiIndex` columns), deduplication, and safe missing-value imputation.
- **Visualizations:** Custom Python charts generated to support the overall data narrative.

##  How to Run locally

1. **Clone the repo:**
   ```bash
   git clone [https://github.com/](https://github.com/)<YOUR-USERNAME>/wildlife-collision-analysis.git
   cd wildlife-collision-analysis
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Notebook:**
   Launch `notebooks/` in Jupyter Lab, Jupyter Notebook, or Google Colab.
